# Шаблон промпта: Агрегатор новостей с проверкой ссылок

## Обзор
Данный шаблон предназначен для языковых моделей с поддержкой активного веб-поиска (Web Search / Grounding). Он гарантирует сбор актуальных новостей по заданным темам и предотвращает **галлюцинацию URL-адресов** (нерабочие ссылки, ошибки 404) и **попадание устаревших новостей**.

---

## Шаблон (Template)

```text
Выполни веб-поиск в режиме реального времени и найди последние новости по теме [ЛОКАЦИЯ / ОТРАСЛЬ / КОНТЕКСТ], опубликованные строго за [ВРЕМЕННОЙ ИНТЕРВАЛ] по следующим направлениям:
1. [ТЕМА 1]
2. [ТЕМА 2]
3. [ТЕМА 3]
4. [ТЕМА 4]

### Строгие правила по контенту и временным рамкам
- Временные рамки: Включай ТОЛЬКО новости, опубликованные за [ВРЕМЕННОЙ ИНТЕРВАЛ]. Все более старые новости должны быть полностью исключены.
- Точность важнее количества: Не придумывай, не додумывай и не дублируй новости ради достижения целевого количества. Если за указанный период найдено меньше новостей, выведи только реально найденные и проверенные факты (но не более [МАКСИМАЛЬНОЕ КОЛИЧЕСТВО ЭЛЕМЕНТОВ]).

### Строгие правила по ссылкам и URL (КРИТИЧЕСКИ ВАЖНО)
- Точность ссылок: Каждый пункт ДОЛЖЕН содержать прямую HTML-гиперссылку (<a href="URL" target="_blank">[ФОРМАТ ТЕКСТА ССЫЛКИ]</a>).
- Запрет на галлюцинацию URL: Категорически ЗАПРЕЩЕНО угадывать, изменять, сокращать или конструировать URL-адреса. Используй ТОЛЬКО точные и полные веб-адреса, полученные напрямую из результатов поиска.
- Требование к источнику: Если в результатах поиска нет прямой проверенной ссылки на конкретную статью, полностью исключи эту новость из выдачи.

### Требования к формату вывода
- Язык ответа: [ЯЗЫК ВЫВОДА]
- Формат вывода: [ФОРМАТ ВЫВОДА]
- Структура каждого пункта: 
  [ШАБЛОН СТРУКТУРЫ ЭЛЕМЕНТА]
```

## Справочник плейсхолдеров

| Плейсхолдер | Тип | Описание | Примеры значений |
| :--- | :--- | :--- | :--- |
| `[ЛОКАЦИЯ / ОТРАСЛЬ / КОНТЕКСТ]` | Строка | Географический регион, сфера бизнеса или контекст. | `Португалия`, `Рынок ИИ в США`, `Финтех в Европе` |
| `[ВРЕМЕННОЙ ИНТЕРВАЛ]` | Строка | Точное окно публикации относительно момента запроса. | `ПОСЛЕДНИЕ 24 ЧАСА`, `ПОСЛЕДНИЕ 7 ДНЕЙ`, `СЕГОДНЯ` |
| `[ТЕМА 1..N]` | Список | Ключевые организации, законы, события или темы. | `AIMA`, `Визы цифровых кочевников`, `SEF` |
| `[МАКСИМАЛЬНОЕ КОЛИЧЕСТВО]` | Число | Максимальный лимит пунктов в ответе. | `10`, `15`, `20` |
| `[ФОРМАТ ТЕКСТА ССЫЛКИ]` | Строка | Текст, который будет внутри тега `<a>`. | `Название источника`, `Заголовок статьи` |
| `[ЯЗЫК ВЫВОДА]` | Строка | Язык, на котором модель должна составить сводку. | `Русский`, `English`, `Español` |
| `[ФОРМАТ ВЫВОДА]` | Строка | Форматирование текста или кода. | `HTML-фрагмент (<ul> и <li>)`, `Markdown-список` |
| `[ШАБЛОН СТРУКТУРЫ]` | Строка | Пример оформления одной строки. | `<li>[Краткая сводка] — <a href="URL">[Источник]</a></li>` |

---

## Требования к исполнению

1. **Включенный веб-поиск**: Среда выполнения (API или интерфейс) должна обязательно иметь включенную функцию **Web Search / Grounding**. Без доступа к поиску модель начнет генерировать несуществующие ссылки.
2. **Гибкое количество**: Не задавайте жесткий минимум (например, «ровно 20 новостей»). Если новостей за 24 часа мало, жесткие ограничения заставят модель брать старые статьи или выдумывать URL.

## Пример использования

### Заполненный промпт
```text
Выполни веб-поиск в режиме реального времени и найди последние новости по теме иммиграции в Португалию, опубликованные строго за ПОСЛЕДНИЕ 24 ЧАСА по следующим направлениям:
1. AIMA
2. Изменения в работе SEF
3. Временная защита для украинцев

### Строгие правила по контенту и временным рамкам
- Временные рамки: Включай ТОЛЬКО новости, опубликованные за ПОСЛЕДНИЕ 24 ЧАСА. Все более старые новости должны быть полностью исключены.
- Точность важнее количества: Не придумывай, не додумывай и не дублируй новости ради достижения целевого количества. Если за указанный период найдено меньше новостей, выведи только реально найденные и проверенные факты (но не более 10).

### Строгие правила по ссылкам и URL (КРИТИЧЕСКИ ВАЖНО)
- Точность ссылок: Каждый пункт ДОЛЖЕН содержать прямую HTML-гиперссылку (<a href="URL" target="_blank">Название источника</a>).
- Запрет на галлюцинацию URL: Категорически ЗАПРЕЩЕНО угадывать, изменять, сокращать или конструировать URL-адреса. Используй ТОЛЬКО точные и полные веб-адреса, полученные напрямую из результатов поиска.
- Требование к источнику: Если в результатах поиска нет прямой проверенной ссылки на конкретную статью, полностью исключи эту новость из выдачи.

### Требования к формату вывода
- Язык ответа: Русский
- Формат вывода: Чистый HTML-фрагмент с использованием <ul> и <li>
- Структура каждого пункта: 
  <li>[Краткая сводка новости] — <a href="ТОЧНЫЙ_URL" target="_blank">[Название источника]</a></li>
```

### Ожидаемый результат
```html
<ul>
  <li>AIMA открыла новый центр обслуживания в Лиссабоне для ускорения обработки заявок — <a href="https://example.com/aima-news" target="_blank">Público</a></li>
  <li>Продление статуса временной защиты для украинцев опубликовано в официальном вестнике — <a href="https://example.com/ukraine-status" target="_blank">Diário de Notícias</a></li>
</ul>
```
